# QR-Code 產生器   網址：https://achir1015.github.io/QR-Code/
QR Code 產生器 含網址、說明文件皆可以產生QR Code
<img width="1678" height="929" alt="image" src="https://github.com/user-attachments/assets/ab9b42d7-a3cc-4579-8b21-287ce536e4a9" />

01、基本功能：

輸入文字或 URL 資料來生成 QR Code
指定檔案名稱
下載為 PNG 圖檔（檔名以您輸入的名稱為準）


02、額外功能：

調整 QR Code 大小（100px 到 1000px）
自訂 QR Code 顏色
高品質 QR Code（使用 H 級錯誤修正）


03、使用說明：

在文字區域輸入您想轉換為 QR Code 的內容
輸入所需的檔案名稱（不需要包含副檔名）
點擊「產生 QR Code」按鈕
點擊「下載 PNG 圖片」保存圖片到您的設備
